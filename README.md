# Сайт ЗАРС — Будинки Каркашадзе

Три сторінки про будівельний холдинг ЗАРС і два його будинки на Французькому бульварі в Одесі.
Статичний сайт без кроку збірки: GitHub Pages віддає файли як є.

```
index.html    Холдинг — спадщина Каркашадзе, правила, цифри, два будинки
fb29.html     Французький бульвар, 29 — зданий, лауреат International Property Awards
fb29b.html    Французький бульвар, 29Б — будується, IV квартал 2026
```

## Як правити текст

Відкрийте потрібний `.html` у будь-якому редакторі й правте текст між тегами.
Нічого запускати не треба — збережений файл одразу є сайтом.

## Куди йдуть заявки

У `js/zars.js` на початку файлу є рядок:

```js
const LEAD_ENDPOINT = '';
```

Поки він порожній, форма не вдає, що заявку надіслано, — вона чесно просить зателефонувати.
Щоб увімкнути форму, вставте сюди адресу веб-застосунку Google Apps Script, який пересилає
заявку в Telegram-канал. **Токен бота не можна класти в цей файл** — код сайту бачать усі.
Схема та сама, що в наявних ботах `ps-leads-bot` і `zars-ua/ZARS_estate-bot`.

Форма надсилає: ім'я, телефон, обраний будинок, коментар, сторінку та час.

```

```

## Як перезібрати ассети

Вихідні матеріали (фірмовий стиль, буклети, фото) лежать **поза репозиторієм** —
у папках `~/Desktop/ЗАРС`, `~/Desktop/ФБ29а`, `~/Desktop/ФБ29б`.
Скрипти в `tools/` потрібні лише тоді, коли ці матеріали змінюються.

```bash
python3 tools/build_images.py      # фото → WebP у кількох ширинах
python3 tools/build_plans.py       # поверхові плани з буклетів → WebP
python3 tools/build_map.py         # берегова лінія з assets/map/osm-raw.json
python3 tools/build_plate_html.py  # блоки вибору поверху → tools/partials/
python3 tools/inline_partials.py   # вставити спільні шматки у сторінки
bash    tools/build_video.sh       # петля для героя 29Б (потрібен ffmpeg)
```

Потрібні: Python 3 з Pillow, PyMuPDF, NumPy, fontTools; ffmpeg — лише для відео.

## Джерела даних

- Цифри про холдинг і будинки — zars.ua та передані буклети.
- Берегова лінія та вулична мережа — OpenStreetMap (© учасники OpenStreetMap, ODbL),
  запит лежить у `tools/overpass.txt`, відповідь — у `assets/map/osm-raw.json`.
- Координати будинків — геокодер Nominatim.
